# Custom Keyboard (블루투스 커스텀 키보드 앱)

내가 원하는 위치/크기/색깔/모양으로 키를 배치해서 나만의 블루투스 키보드를 여러 개 만들고,
그 중 하나를 실행하면 폰 화면이 진짜 키보드가 되어 눌렀을 때 컴퓨터로 바로 입력되는 앱입니다.

## 핵심 동작 방식
- 안드로이드의 `BluetoothHidDevice` API로 폰을 **진짜 블루투스 HID 키보드**처럼 컴퓨터에 등록합니다.
- 그래서 윈도우/맥 상관없이, 일반 블루투스 키보드 페어링하듯 페어링하면 바로 인식되고,
  중간에 별도 프로그램/드라이버 설치가 필요 없습니다.
- 키를 누르면 표준 HID 리포트(8바이트: modifier + reserved + keycode)를 즉시 press → release로 전송해서
  체감 딜레이를 최소화했습니다.

## 기능
- 메인 화면: 만들어둔 키보드 레이아웃 목록 (여러 개 저장 가능), 블루투스 연결 상태 표시
- 편집 화면: 
  - `+` 로 키 추가
  - 키를 드래그해서 **위치** 이동, 모서리 드래그로 **크기** 조절
  - 탭하면 상세 설정: **어떤 키인지**(A-Z, 0-9, F1~F12, 방향키, Enter/Esc/Tab 등 특수키), 
    **Ctrl/Shift/Alt/Win 조합**, **RGB 슬라이더로 색깔**, **모양**(사각/둥근사각/원), **크기**
- 실행 화면: 만든 키보드가 그대로 뜨고, 누르면 컴퓨터로 입력 전송 + **키마다 누른 횟수 카운트 표시**

## 이 프로젝트를 APK로 만드는 방법

### 방법 A — GitHub Actions로 자동 빌드 (추천, PC 필요 없음)
1. GitHub에 새 저장소를 만들고 이 폴더 전체를 업로드(푸시)합니다.
2. GitHub 저장소 페이지 → **Actions** 탭 → `Build APK` 워크플로우가 자동 실행됩니다.
   (수동 실행하려면 Actions 탭에서 `Run workflow` 클릭)
3. 빌드가 끝나면 해당 워크플로우 실행 결과 페이지 하단 **Artifacts**에서
   `custom-keyboard-debug-apk`를 다운로드하면 그 안에 `app-debug.apk`가 들어있습니다.
4. 그 apk 파일을 폰으로 옮겨서 설치하면 됩니다. (출처를 알 수 없는 앱 설치 허용 필요)

### 방법 B — Android Studio로 직접 빌드
1. Android Studio에서 이 폴더(`CustomKeyboard`)를 **Open** 으로 엽니다.
2. Gradle Sync가 끝날 때까지 기다립니다 (인터넷 필요, Google Maven 저장소 접근).
3. 상단 메뉴 **Build → Build Bundle(s) / APK(s) → Build APK(s)**
4. 빌드 완료 알림에서 `locate` 클릭하면 `app-debug.apk` 위치가 열립니다.

## 사용 순서 (앱 실행 후)
1. **컴퓨터의 블루투스 설정**에서 새 기기 추가 → 폰 이름(CustomKeyboard로 등록됨)을 찾아서 페어링합니다.
   (앱을 먼저 한 번 실행해서 HID 서비스가 등록된 상태여야 컴퓨터 쪽에서 검색됩니다)
2. 앱 홈 화면 상단 **블루투스** 버튼 → 페어링된 기기 목록에서 컴퓨터 선택 → 연결
3. `+` 버튼으로 원하는 키보드 레이아웃을 만들고 저장
4. 목록에서 ▶(실행) 눌러서 키보드를 띄우고 사용

## 참고 / 제한사항
- `minSdk = 31` (Android 12 이상)로 설정했습니다. 더 낮은 버전 기기가 필요하면 `app/build.gradle.kts`의
  `minSdk` 값을 28까지 낮출 수 있습니다 (HID Device API는 Android 9/API 28부터 지원).
- 최초 실행 시 블루투스 권한(연결/스캔/광고)을 허용해야 정상 동작합니다.
- 저는(어시스턴트) 이 프로젝트를 직접 컴파일해서 apk 바이너리로 검증하지 못했습니다
  (샌드박스 네트워크가 Android SDK 저장소 접근을 막고 있음). 문법/로직은 신경 써서 작성했지만,
  최초 빌드에서 사소한 오류가 나면 에러 메시지를 알려주시면 바로 고쳐드릴게요.
